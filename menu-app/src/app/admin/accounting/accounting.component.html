ℹ️ How to import into Tally
  1. Open TallyPrime → Gateway of Tally → Import → Masters and choose the ledgers file. Do this once, and again whenever new customers or suppliers appear.
  2. Then Import → Transactions and choose the vouchers file.
  3. Re-importing the same dates? When Tally asks about existing vouchers, choose Replace so edited bills update instead of duplicating.

What gets created: one Sales voucher per day, one Receipt voucher for udhaar received, one Payment voucher for salaries, and one Purchase voucher per supplier invoice (plus a Payment voucher when it is paid).
